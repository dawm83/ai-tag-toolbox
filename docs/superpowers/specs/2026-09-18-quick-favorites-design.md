- 文档日期：2026-09-18。
- 源码基线：`ai-tag-release-v143`，V1.4.32，提交 `bdde91e80fecfc0037ad5b329c4dd0b79c3d752e`。
- 状态：已讨论方案的设计归档。本文和配套计划不代表功能已经实现。
- 配套实施计划：[快捷收藏页更新计划](../plans/2026-09-18-quick-favorites-plan.md)。
- 首个功能测试版建议：V1.4.33；本次只提交文档，仍为 V1.4.32。

## 1. 目标与共识

收藏页的首要目标是快捷编辑、复制、修改、查找。它是一个可以自行整理的 Tag 收藏架，使用现有标签的视觉风格和操作习惯。

用户明确提出并在讨论中保留的要求：

| 编号 | 设计要求 |
| --- | --- |
| R01 | 独立快捷收藏页面，可保存站内单个 Tag、多个 Tag 的组合和自由输入内容 |
| R02 | 多列并排，每个系列内部竖向排列，能同时浏览多个系列 |
| R03 | 用户可新增系列和子分类，顶部快捷栏可定位 |
| R04 | 单 Tag 复用现有样式；组合风格相近、有明显区别，可展开查看 |
| R05 | 部分条目可加中文说明、别名和备注 |
| R06 | 独立内部搜索只查收藏内容，不混入基础词库 |
| R07 | 自定义内容默认允许参与全局查询，用户可关闭；内部搜索不受此开关影响 |
| R08 | 新系列自动选择与之前有区别的颜色，支持系列级批量改色和自定义颜色 |
| R09 | 复制、编辑入口直接可见，尽量就地完成修改 |
| R10 | 支持收藏内容缩放，保存布局、顺序和显示偏好 |
| R11 | 搜索高亮命中内容、显示所属位置、定位原处并恢复浏览上下文 |
| R12 | 沿用当前项目，不建立完整电子表格、复杂框架或额外权限系统 |

为避免执行时各自猜测，以下采用本设计的默认规则，可在实现前随用户反馈调整：

- 一个系列对应一列；子分类是该列内的小标题，最多两层分类。
- 系列颜色表示归属；单标签/组合通过图标、数量和底色差异进一步区分。
- 主体点击沿用现有普通 Tag 的“选中/取消并复制”；独立复制按钮不改变底部组合。
- 收藏的原始内容是复制和使用的权威来源；名称、中文说明、备注不会进入 Prompt。
- 收藏组合在底部作为整体显示，使用时保存快照，取消该组不删除其他来源的选择。
- 新建条目默认 `globalSearchable: true`；开关同时作用于站内全局搜索和 AI Tag 查询。内部搜索另行处理。
- 已有成人内容开关继续适用；自录条目可手工设置成人标记，不引入自动内容分类器。

## 2. 页面结构与定位

```text
现有顶部导航：Tag / AI / 翻译 / 图库 / 快捷收藏
收藏工具条：仅搜索收藏 | 搜索范围 | 新增 | 撤销/重做 | 批量操作 | 显示 | 缩放
系列快捷栏：画风、构图、服装……（当前系列可显示子分类定位按钮）

画风                    构图                    服装
  常用画风                视角                    日常
    单标签                  单标签                  单标签
    标签组                  标签组                  标签组
  画师组合                镜头                    配饰
    标签组                  单标签                  单标签

底部沿用当前 Prompt 组合栏
右侧按需打开当前条目的完整内容/编辑区
```

### 2.1 浏览布局

- 列为不带外层装饰卡片的连续区域，标题使用系列颜色，条目沿用现有 chip 视觉。
- 默认列宽 280px，支持调整列宽并记忆；条目占满所在列，文本允许换行。
- 使用一个收藏内容滚动容器，避免每列独立滚动条。
- 宽度不足时横向滚动，不把用户手动排序重排成瀑布流。
- 新系列追加到右侧，新条目追加到目标分类末尾；不因使用次数而自动换位置。
- 系列标题随内容纵向滚动保持可见，顶部工具栏与快捷栏固定在收藏页内。
- 视口很窄时编辑区改为覆盖式侧栏；关闭后还原原焦点和收藏架位置。
- 全量收藏都可以访问。“加载更多”或延迟渲染不能造成条目被永久截断。

### 2.2 快捷定位

- 顶部系列按钮滚动定位到对应列，而不是默认隐藏其余列。
- 当前系列的子分类按钮可定位到该列内的小标题。
- 系列太多时快捷栏水平滚动，并提供可搜索的系列菜单；不让顶部无限换行挤占内容区。
- 定位时同时处理横向、纵向位置，目标标题/条目短暂强调并获得可见焦点。
- 固定手动顺序是主要定位依据；新增和复制不打乱已有位置。
- 每个系列可以置顶少量条目；置顶标记显式存在，不把“最近复制”自动塞到系列顶部。

## 3. 单标签与标签组

| 项目 | 单标签 | 标签组 |
| --- | --- | --- |
| 主信息 | 英文原文或中文说明，取决于显示偏好 | 用户命名 |
| 次信息 | 中文说明或英文原文 | 内容预览、可解析时的成员数量 |
| 类型识别 | 单标签样式 | 组合图标、数量、同系列的不同底色强度 |
| 复制 | 复制原文 | 复制整组原文 |
| 加入底部 | 一个收藏选择项 | 一个整体组合项 |
| 展开 | 较长备注/完整内容 | 完整组合内容及说明 |
| 修改 | 单项编辑 | 编辑整组原文，不自动重排成员 |

- 单标签与组合可以混排在一个子分类下。
- 自由输入不要求先在基础词库中注册，不调用 `tags.addCustom()` 偷偷同步一份数据。
- 原文保持大小写、空格、逗号、权重括号、转义和换行；搜索用的标准化文本单独派生。
- 类型由用户选择。复杂 Prompt 不能仅因包含逗号就被强行拆开或更改类型。
- 组合成员数量是展示信息。仅在现有解析能力能识别完整 Tag 单元时显示具体数量；无法判断时显示“组合”，不把英文短语的单词数当 Tag 数。
- 备注可以写在某个单标签或整个组合上；组合内部逐词独立备注不作为第一版强制能力。
- 相同内容允许存在于不同系列，分别有自己的名称、说明和备注；编辑一个副本不修改其他副本。

## 4. 操作规则

### 4.1 日常操作

| 操作 | 结果 |
| --- | --- |
| 点击条目主体、焦点在主体时按 Enter/Space | 切换该条目在底部组合中的选中状态，并尝试复制该条目原文；复制失败明确提示 |
| 点击复制图标 | 只复制，不改变底部选中状态 |
| 点击编辑图标或聚焦条目后 F2 | 打开对应的行内编辑/侧边编辑区 |
| 点击展开图标 | 查看完整内容，不改变底部选中状态 |
| 点击批量勾选框 | 只改变管理操作选择，不改变底部 Prompt |
| Ctrl+C | 输入框或文本选区存在时遵从原生行为；否则复制当前聚焦条目的原文 |
| Esc | 先取消当前编辑/关闭当前面板，不清空收藏或底部组合 |

复制、编辑、展开、管理勾选应为可聚焦的独立控件，不嵌套 button。复制/编辑常驻显示，名称由 tooltip 和 aria-label 给出。

### 4.2 编辑与自动保存

- 短名称和说明就地编辑；长原文和备注在侧边编辑区编辑。
- 编辑区固定显示当前系列/子分类，提供上一条、下一条；顺序以打开编辑时的可见结果 ID 列表为准。
- 输入期间维护独立草稿，约 300ms 合并提交；输入法组合输入期间不提交。
- 切换条目、离开收藏页、导出、复制当前草稿及窗口关闭前先提交有效草稿并等待保存。
- 原文为空或校验失败时保留编辑草稿及此前保存值，不用空字符串覆盖旧收藏，也不自动换到下一条。
- 保存状态区分“编辑中 / 保存中 / 已保存 / 保存失败”。“已保存”必须来自实际 `flush()` 的结果。
- 若退出时草稿无效，留在当前编辑区；如果用户明确取消编辑，则恢复此前保存值。
- 不每输入一个字就重建整列、移动焦点或关闭正在编辑的条目。
- 在搜索结果里编辑时保留该行到本次编辑结束；再重排结果，避免修改名称时条目突然消失。

### 4.3 批量管理

- 支持多选后移动、复制、删除、置顶/取消置顶、开启/关闭全局搜索。
- 多系列颜色操作在系列菜单中完成，不让条目勾选悄悄改变整个系列颜色。
- 操作前显示明确作用范围和数量：已选条目、当前系列或当前搜索结果。
- “当前搜索结果”覆盖全部命中 ID，不仅当前渲染的一页。操作启动时冻结 ID 集合。
- 不提供模糊的“全选全部”：按钮必须说明选择范围。
- 复制条目创建新 ID，原文/说明相同，后续独立修改。
- 删除系列默认把条目移到“未分类”；彻底删除系列及内容是另一个明确命令。
- 删除子分类默认把条目移到同系列根部。
- 删除、移动、改色、批量修改和编辑可以撤销/重做；本轮内至少保留最近 30 个操作，内存历史只保存受影响记录，不复制整份收藏库。
- 一次连续输入合并成一次撤销记录；切换条目、失焦或显式保存结束该编辑事务。
- Ctrl+Z 在输入框内优先恢复正在输入的文本；页面级撤销不截获原生文本撤销。

## 5. 收藏内部搜索

### 5.1 范围

- 搜索栏提示为“搜索收藏”，只查询收藏模块。
- 默认全部系列；可限定某系列、子分类，或只看单标签/标签组。
- 匹配字段：名称、原文、中文说明、别名、备注、系列/子分类名称。
- `globalSearchable=false` 的条目仍参与内部搜索。
- 成人开关继续过滤标记条目，界面明确存在被隐藏内容；搜索关闭可发现性与成人过滤不是同一件事。
- 搜索不触发 AI、网络请求或基础词库重新加载。

### 5.2 命中与呈现

- 优先级：名称/原文精确命中 > 名称/原文前缀 > 别名/中文说明 > 内容包含 > 备注/分类名称。
- 同分时使用现有系列/分类/条目顺序，保证结果稳定。
- 查询多个词时按 AND 匹配，各词可命中不同字段。
- 高亮原始文本中的命中位置，使用 text node/mark，不把用户输入当作 HTML。
- 权重、下划线等归一化只影响匹配；显示和复制原文不能被改变。
- 标签组成员命中时，在结果里显示包含命中词的内容片段，不能只显示组名。
- 每项显示所属路径，例如“构图 / 视角”，并保留复制、编辑、定位原处。
- 搜索结果先呈现 80 条，可继续加载；总数准确，批量命中操作不受分页影响。
- 清空搜索恢复搜索前的横向/纵向位置、折叠状态和焦点。
- “定位原处”退出结果视图、展开目标分类、滚动到条目；允许返回原搜索及结果位置。
- 内容修改、移动、改色、可发现性切换、撤销、导入后立即使旧索引失效；异步 UI 任务用请求序号避免旧结果回写。

## 6. 全局查询与 AI 查询边界

| 场景 | 内部搜索 | 主 Tag 页搜索 | AI tags.search |
| --- | --- | --- | --- |
| 默认新建条目 | 可查 | 可查，单独标注“收藏” | 可查，按收藏结果单独返回 |
| 关闭全局搜索 | 仍可查 | 不返回该收藏条目 | 不返回该收藏条目 |
| 同词已有基础 Tag | 仍是独立收藏 | 基础 Tag 不会被该开关删除 | 基础词结果保持原有行为 |
| 标签组 | 完整组 + 命中片段 | 独立的组结果，不伪装成一个 Tag | 独立 favorites 字段，kind=bundle，原文完整或明确不可完整返回 |

接入方式：

- 不把收藏反向写入基础词库，不改 `tags.js` 的存储、原有排序或分类数量。
- 主 Tag 页存在搜索词时，追加独立“我的收藏”结果区域，调用 `favorites.search(..., {scope:'global'})`。
- `tags.search` 保留现有 `items` 返回结构，只在有命中时增加可选 `favorites` 数组；工具名称和数量不增加。
- AI 返回收藏的名称、kind、原文、中文说明、所属系列和可解析成员数量；个人备注不自动发给模型。
- 全局查询只匹配名称、原文、中文说明和别名；备注仅参与内部查找，避免全局返回一个没有可见命中依据的条目。
- 外部查询结果数量有小上限，默认最多 8 个完整收藏；总原文预算为 16,000 个字符。无法完整容纳的长组仅返回名称、ID 与 `contentOmitted:true`，不把截断文本冒充可直接使用的 Prompt。
- 工具说明明确自定义内容来自用户收藏，不代表基础词库已确认含义。查询只提供内容，不能修改收藏或自动加入 Prompt。
- 这是同一收藏搜索逻辑的两个出口，不新增搜索服务、向量库或第二套可编辑数据。

## 7. 系列颜色与显示偏好

### 7.1 颜色

- 创建系列时从 10 色预设中选未使用/较少使用颜色，优先避开左右相邻系列；相同使用次数按预设顺序决定。
- 自动配色结果创建时落盘。以后添加新系列不重新给旧系列换色。
- 多于色板数量时允许重复，不承诺无限不重复；相邻区分优先。
- 系列具有 `colorMode:'auto'|'custom'` 和最终 `color`。自定义使用色板或 HEX/原生颜色选择器。
- 一次改某系列颜色即可同步标题、顶部定位按钮、所属条目强调色。
- 多选系列批量统一颜色，或批量恢复自动配色；一次操作可撤销。
- 第一版不增加每条收藏独立覆盖颜色的优先级系统。
- 选中勾选、类型图标、文字标签都独立于颜色。
- 自定义颜色主要用于边线、色块与浅背景；正文仍使用主题文字色，避免用户选浅色后文字不可读。浅色/深色主题都验收。

### 7.2 缩放和阅读

- 内容缩放 75%–150%，10% 步进，支持输入百分比与恢复 100%；只影响收藏内容区。
- 使用固定字体基础尺寸乘缩放值，不按窗口宽度直接缩放字号。
- 工具栏保持可点击尺寸；快捷栏和滚动坐标正确响应内容尺寸变化。
- 支持“英文优先 / 中文优先 / 紧凑”三种全局显示方式。
- 紧凑不意味着隐藏类型、复制入口或完整内容访问方式。
- 列宽、缩放、显示方式、排序、折叠状态保存在收藏专用偏好中；不改全应用 Electron zoom。
- “最近复制”保存最近 20 个成功复制的条目 ID，去重后最近在前，是快捷视图，不改原来的物理顺序。

## 8. 底部组合与复制契约

- 普通 Tag 的选择仍归 Tags，角色选择仍归 Characters。
- 收藏模块只拥有 `favoriteSelections`，每个选择项保存加入时的 `entryId/kind/title/rawText/nsfw` 快照。
- 同一收藏 ID 再次点击为取消，不重复追加；不同收藏 ID 即使内容相似仍是独立选择。
- 底部使用组合图标和名称显示收藏组，可展开查看快照内容；移除仅影响该收藏选择项。
- 编辑或删除收藏条目不偷偷修改已加入 Prompt 的快照。需要更新时取消后重新加入；条目已修改可用轻量状态标记说明。
- 普通词与角色的现有去重行为保留；收藏原文作为独立块按选择顺序追加。
- 不自动拆解组合、删除组内重复词或合并不同权重。第一版不做跨组“智能去重”。
- 全部复制：普通/角色输出在前，收藏块按加入顺序在后；块间补一个必要逗号分隔，块内原文保持原样，末尾已有分隔符时避免额外重复分隔符。
- 单条复制只复制 `rawText`；多条批量复制按当前列表顺序组装，不带中文说明、备注和路径。
- 底部“清空”清空普通、角色、收藏三类选择，收藏架本身不删除。
- “收藏当前组合”读取最终组合内容，保留当前角色已输出的文本；建立普通收藏快照，不增加活的角色引用关系。
- 不把新收藏页默认等同于 AI 自动读取底部组合；现有聊天发送是否使用底部内容的契约保持原样。

## 9. 数据与职责

### 9.1 数据结构

使用现有 JSON Storage，新增 `favorites_shelf_v1` 与 `favorites_selection_v1`。最近复制的 20 个 ID 存入 `favorites_recent_v1`；收藏视图偏好写入现有 preferences 下的 `favorites.view`。前三者均由 Favorites 模块拥有，View 只保存显示偏好。

```json
  "version": 1,
  "revision": 1,

  ],
  "sections": [
    { "id": "section-portrait", "seriesId": "series-light", "name": "人像", "order": 0 }

      "aliases": ["柔光", "逆光"],

      "globalSearchable": true,
      "pinned": false,
      "nsfw": false,
      "order": 0,
      "sourceTagId": null,
      "createdAt": 0,
      "updatedAt": 0
    }
  ]
}
```

- `id` 是稳定 ID，与名称、内容和顺序无关；重命名不改 ID。
- `sectionId:null` 表示系列根部条目；同名系列/条目允许，完整路径用于消歧。
- `rawText` 是唯一内容源。成员数量、搜索索引、主题色变体均派生，不另存可编辑副本。
- `sourceTagId` 仅记录来源，不决定复制时读取哪份内容。
- `revision` 只在实际内容/结构写入后增加；用于局部刷新和搜索缓存失效，不用于复杂并发协议。
- 已选收藏快照单独保存，名称/备注编辑不会通过共享对象污染当前 Prompt。
- 历史撤销/重做是当前进程的有界内存记录，不另建日志系统。

## 10. 旧收藏、批量录入与备份

### 10.1 旧收藏迁移

- 首次新键不存在时，读取 `rewrite_favorites`，迁入“未分类”系列。
- 已知 Tag ID 展开为当时的英文内容；找不到的非空 ID 原样保留，并在迁移报告中列出。
- 空或异常旧条目保留原始记录用于恢复，显示为待补内容且禁止复制空结果，不静默删除。
- 新键有效时不重复迁移，不把多次启动变成多份收藏。
- 保留旧键，不回写旧格式，不在本轮清掉恢复来源。
- 新键损坏时明确报错并保留原数据，不能按“空收藏”覆盖。
- 迁移前后条目数量、名称、原文与未解析项必须有自动测试。

### 10.2 粘贴与导入

- 新增面板支持直接输入单标签/组合。
- 批量粘贴两种模式：一行一条，或 TSV 的“内容 + 中文说明”两列。
- 默认每行一条，不按逗号自动把整组拆成多条；类型可在预览中选择。
- TSV 使用成熟解析器处理制表符、引号和单元格内换行；不把截图 OCR 当作用户原文导入。
- 提交前预览目标系列、有效数量、重复项和错误行；有错误时指出行号，用户修正后再导入。
- JSON 导出保留系列、分类、颜色、原文、注释、排序、开关；不含 API Key、聊天或图片。
- JSON 备份不含当前底部选择、最近复制记录、撤销历史或临时搜索；缩放和滚动属于本机显示偏好。
- JSON 默认追加；ID 冲突分配新 ID 并同步映射关系，不按标题覆盖。
- 替换导入明确显示将替换的数量，并先提供现有 JSON 备份；一次提交可撤销。
- 未知较新格式版本拒绝导入，不猜测结构。畸形记录不半成功写入。
- 暂不解析 .xlsx 合并单元格、公式或嵌入图片；保留直接粘贴即可完成常用迁移。

## 11. 性能与可用性验收

以下是实施验收目标，不是当前已测结果：

- 固定测试数据：20 系列 × 5 子分类 × 30 条 = 3,000 条，其中 600 个组合，1,000 条备注；另测 10,000 条压力数据。
- 首次进入收藏页不要求一次构造所有条目 DOM；使用现有批量渲染经验，按系列/批次加载，定位能主动加载目标。
- 3,000 条内的纯搜索预热后 p95 目标不高于 50ms；目标机器记录 CPU、Node/Electron 版本和实际时间。
- 局部改一个备注不全页重建，复制操作不等待全库保存或网络。
- 100 次进入/离开页面后不重复绑定事件；退出页面取消无效搜索/渲染任务。
- 初始内容渲染目标 200ms 内完成，额外批次异步补齐；达不到先测具体热点，不立即引入虚拟列表依赖。
- 980×680、1360×900、1920×1080；75%、100%、150%；浅色/深色主题都检查长文本、图标、焦点和编辑区无重叠。
- 所有可点击条目有键盘等价操作；输入状态下页面快捷键不抢输入框行为。
- 数据/草稿必须以纯文本渲染，复用当前存储错误通知和关闭保存流程，不新增权限系统。
- 行为回归走 `npm run check`；真实 Electron、剪贴板、缩放布局由用户人工验收。默认不运行 --uitest/--smoke/--i18ntest。

## 12. 第一版与暂缓范围

第一版包含：

- 独立页面、系列/子分类、多列纵向布局、快捷定位。
- 单标签/组合/自由输入、中文说明/别名/备注、直接复制与编辑。

- 全项目 Tags/Characters/选择状态的统一重构。
- 全局样式重做与浏览器框架迁移。
