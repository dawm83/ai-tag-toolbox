# 统一标签候选版：人工验收清单

状态：尚未进行真实 Electron 窗口验收。此文件列出候选版交付后需要核对的行为，不能把自动化 DOM 检查等同于这些实测结果。

## 开始前

关闭旧版工具箱，再打开候选版。首次打开会从原用户目录迁移旧数据；安装目录不携带用户收藏、设置、聊天或 API 配置。旧版无法读取新版标签库，切回旧版也不会同步新版修改。

测试现有收藏前可先导出备份。测试新增数据可使用名称“统一测试”，完成后取消这些收藏并删除不再被引用的自定义条目。

| --- | --- | --- | --- |
| 1 | 首次打开，查看迁移摘要；退出并再次打开 | 旧页、分组、顺序、颜色保留；差异条目独立保留并有说明；第二次不会重复迁移 | 待验收 |
| 2 | 主页找到蓝发，点收藏；选已有收藏页和分组 | 在当前位置完成收藏，无需跳去收藏页填写第二份内容；原标签 ID 和总数不变 | 待验收 |

## 故障与恢复验收

保存失败、磁盘空间不足、旧文件损坏和并发迁移等故障由自动化夹具验证，不要求在真实用户数据上制造损坏。若候选版真实启动提示迁移失败，应先关闭其他旧版实例，再使用重试；若提示新版库损坏，应保留原文件并使用明确的备份恢复入口，不能删除库来绕过错误。

如果准备切回旧版本，先导出新版中需要保留的数据。旧存储键作为迁移来源留存，不能视为新版修改的实时备份。
