# 内置标签中文与分类补全

构建模块：`src/modules/tag-library/enrichment.js`。
显式覆盖表：`assets/数据资产/标签/tag-enrichment.json`。
入口：`enrichBundledTags(base, coverage?) -> { base, changes, counts }`。

调用位置为 seed 全部标签、分类、角色关系完成之后，计算 fingerprint 之前。函数返回独立副本，不写文件，不计算 fingerprint，不修改输入。父构建流程负责校验、fingerprint 与生成产物。

变更字段严格限定为 `displayName`、`categoryId`、`subcategoryId`。所有 ID、content 原文、aliases、角色引用、usages、成人标记、搜索资格、来源与旧分类/子分类记录均保留。

规则：

1. 普通标签仅在内容经过 NFKC、大小写、空格/下划线规范化后精确匹配时复用中文或分类。不同译名或不同分类存在冲突时不取第一项。别名、显示名、模糊结果均不参与身份匹配。
2. 已有中文保留。空白普通译名可补全；角色仅接受空白或与内容相同的原文回退名。衣装推导仅去除一个已知限定，其余括号内容和作品关系必须精确匹配。作品关系为空、职阶或具名皮肤未知、多重衣装限定、来源译名冲突均保留原文。
3. 衣装组合名是描述性中文，不是官方皮肤名。符华七套装甲及其他明确角色使用独立的内容+作品词表，不扩展推断到其他皮肤。
4. 分类补全仅替换兜底分类，使用现存子分类。专属制服、具名装备仍保留角色专属分类；明确通用的服装/配饰可进入已有细分类，但仍保留 `characterSpecific` 用途与原搜索资格。

具名装甲、校服与角色名称是本轮人工整理词表，未逐条完成官方来源审定。现有中文即使疑似有误也不在本次覆盖范围。衣装角色继续保持 `characterIdentity`，原本隐藏的角色专属词继续保持原搜索资格。
